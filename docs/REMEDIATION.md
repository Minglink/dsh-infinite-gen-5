# 1.0.0 缺陷修复对账（2026-10-10）

本轮修复针对此前代码审计的 R01–R09，并保留 38 个工具、12 个审批工具、Core 8 与 7 个技能包。工具目录数不代表所有逆向问题都能自动解决。

| 编号 | 原问题 | 实际修复与核验 |
| --- | --- | --- |
| R01 | 同路径换样本或数据库，补丁历史可能串线 | 同时核验样本 hash、artifact、attachment 与物理数据库身份；导出前逐字节核验完整文件映射，读取当前数据库字节；Undo 后导出保持原字节。旧无绑定记录拒绝导出。 |
| R02 | Windows 路径大小写导致遗漏历史 | Windows 路径统一规范化并保留 POSIX 大小写区别；独立路径反例通过。 |
| R03 | Worker 输出缓冲与 ready 前消息积压无上限 | UTF-8 字节预算、单行/缓冲/积压上限；超限清理所属 worker 与全部待处理请求。实际洪泛及伴随进程保留测试通过。 |
| R04 | 历史翻页全量同步读取、累计预算导致硬拒绝 | 审计异步尾读与快照 cursor；分析 metadata 异步分批索引并缓存。部分结果标明下限；可恢复归档不删除报告和 blob，历史 ref 保持可用。 |
| R05 | 宿主退出即释放仍存活的 worker 数据库租约 | 记录宿主/worker 创建身份和 nonce，双方确认消亡后才恢复；正常清理等待 worker exit 或数据库 close 确认。无法核实的旧租约保留。 |
| R06 | flow 被候选预算跳过，但顶层仍显示完整 | 覆盖范围、跳过组、原因及顶层 truncated 贯通；分析遗漏和预览省略分别报告。 |
| R07 | 仿真页统一 RWX 且未披露 | 已知 R/W/X 映射到 Unicorn 页权限，读写执行违规分别报告。未知权限兼容 RWX 和同页权限合并均显式披露；真实 Reverse/Ghidra 提供器反例通过。 |
| R08 | 原生事件环溢出误判传输故障、丢失后上下文过期 | 原生丢失区间、运行 epoch、暂停序号；安全暂停后重新对账，保留目标并清除旧缓存，未知历史不伪造命中。x86/x64 真实环溢出验证通过。 |
| R09 | 架构文档仍宣称没有自动恢复和推断 | 文档、维护约定、运行包必需模块和安装预检已同步实际接口与限制。 |

复验新增修复：报告硬链接会覆写源样本，现改为独立 wx 暂存文件再提交；审计预算续读停滞、空文件处理、精确总数误报、损坏 JSON 证据遗漏均有反例回归。补丁导出是二进制与报告分别提交，后者失败明确返回 EXPORT_PARTIAL，不宣称跨文件原子性。

x64dbg 上游普通暂停后单步在自循环上可能超时；固定源码维护补丁 0003 将暂停临时断点改为 UE_SINGLESHOOT，避免内部 ResetBPX 单步遮蔽用户单步事件。批准 start 的异步初始化仅接受预期的下一原生运行 epoch；stop 等待已接受的初始化越过临时 no-task 窗口。维护补丁、上游通知、构建 hash 与实际验收单独保存。

本轮能力增补：单字节 XOR 的 UTF-8 中文与二进制格式候选评分；canonical u32 varint-prefix、有限 TLV 推断/解码；有限算术字段关系、xor8/sum8/CRC32 尾部关系与独立 holdout；现代 DSH 按调用智能体隔离 Core/Full。工作台显示前 8 个候选、前 256 字节，并生成保留 producer/range/key_ref 的待发送草稿。捕获容器不能直接复用为重组报文解码输入。

仍需独立迭代的能力包括：跨基本块的虚调用接收者推导、完整数据流与通用控制流去平坦化、带 OS/导入/TLS 环境的执行、可审阅的完整指令轨迹，以及 Android/iOS 原生离线运行包与真机验收。当前重复 XOR 的统计模型并未覆盖任意中文/二进制；TLV 不解析嵌套结构，协议关系不证明字段语义或完整状态机。强 AES 随机密钥全空间穷举没有现实保证。

审计 cursor 服务于正常追加日志，不提供恶意改写旧前缀并同时追加的完整性链。归档保留数据，当前不自动删除可能仍被用户持有的无绑定引用；它不构成磁盘垃圾回收。

验收日志位于维护机器的 `.dsh/ig5/artifacts/remediation-validation`。语法检查支持 PowerShell 7 和 Windows PowerShell 5.1；详见 `scripts/check_syntax.ps1`。已运行的原始样本仅用于静态读取或复制到临时目录，原文件 hash 另行核对。源码镜像同步不证明正在运行的 DSH 已加载新版宿主代码；默认 HMR root=[] 的安装环境需要正常退出后重开，并核对新的路由挂载时间与 toolsetScope。
