The IG5-specific bootstrap permits one fixed native extension filename and
resolves it through Java's Unicode working directory. Without that property,
upstream path handling is retained. The native extension is not rebuilt.
scripts/patch_ghidra_jpype.ps1 uses the bundled JDK javac --release 8 to replace
only JPypeContext and its nested class entries in the original JAR. Rebuild
source/JAR/patch hashes and origins are recorded in runtime.json.jpypeBootstrap
and licenses/ig5-jpype-bootstrap/provenance.json; seal_runtime_bundle.ps1 updates
the complete runtime inventory afterwards. This modified upstream component
retains its upstream license; IG5's NC condition does not replace it. Frozen
third_party/sources snapshots and their original hashes are not modified.

is part of the upstream x64dbg license. The debugger remains a separate process.
Unicorn: worker/vendor/NOTICE.txt, package metadata and licenses/ contain the
